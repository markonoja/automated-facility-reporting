# \# Automated RADET Data Quality \& Performance Dashboard

# 

# \## Project Overview

# An Excel and Power Query solution designed to automate data-quality checks, identify records requiring corrective action, and monitor reporting performance across health facilities.

# 

# The project uses \*\*300 synthetic RADET records across 10 fictional facilities\*\*. No real patient information is included.

# 

# \## Key Features

# \- 12 automated data-quality checks

# \- Detection of duplicate patient identifiers and cross-facility ID discrepancies

# \- Identification of missing and inconsistent ART and viral load information

# \- Automated Data Quality Resolution Line List

# \- Facility-level and state-level performance summaries

# \- Refreshable Excel dashboard with four key performance indicators

# \- Automated identification of newly introduced data-quality issues

# 

# \## Dashboard Results

# | Indicator | Result |

# |---|---:|

# | Total Records | 300 |

# | Affected Records | 12 |

# | Total DQ Issues | 14 |

# | Records Affected | 4.0% |

# 

# \## Tools

# \- Microsoft Excel

# \- Power Query (M Language)

# \- GitHub Desktop

# 

# \## Validation

# The solution was tested by introducing an abnormal ARV refill duration into a synthetic record. Refreshing the data successfully updated the dashboard and Resolution Line List. The test value was subsequently restored.
